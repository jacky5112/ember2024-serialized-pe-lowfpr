# EMBER2024 Serialized PE Low-FPR

Reproducibility materials for *Evaluating Serialized PE Semantics for Malware Detection under Low-FPR Constraints: A Multi-Format EMBER2024 Study*.

`EMBER2024_MultiPE.ipynb` reproduces the reported analyses from the public EMBER2024 source archives. Numerical outputs are provided in `data/` and generated figures in `figures/`. Raw malware samples and trained model checkpoints are not included.
